# fCraft

Офлайн-клон «кубической песочницы» для Android на **Kotlin**: собственный 3D-рендер (OpenGL ES 3.0),
бесконечная процедурная генерация мира, крафт, печь, сундуки, мобы. Интерфейс — **Jetpack Compose + Material 3**.
Интернет не нужен: все текстуры рисуются кодом при запуске (`core/Textures.kt`), внешних ассетов нет.

## Возможности

- Бесконечный мир: биомы (равнины, лес, пустыня, снежный, горы), океаны, пещеры, лава, руды, деревья, цветы, кактусы, тростник
- Меш чанков с ambient occlusion, небесным и блочным светом, день/ночь, солнце и луна, туман, подводный режим
- Блоки и предметы по мотивам 1.20.1: дерево всех пород, камень и производные, руды, цветные семейства
  шерсти/бетона/терракоты/стёкол, инструменты и броня 6 материалов, еда, материалы
- Верстак 3×3, крафт 2×2 в инвентаре, печь с топливом и плавкой, сундуки. Рецепты: shaped/shapeless, зеркальные, теги (`#planks`…)
- Выживание (здоровье, голод, падение, лава, утопление, броня, прочность) и творческий режим (полёт — двойной прыжок)
- Мобы: свинья, корова, овца, курица, зомби, скелет, крипер (взрывается), паук
- Сохранение миров на устройстве (игрок, инвентарь, печи, сундуки, изменённые чанки)

## Управление

Левый джойстик — движение, перетаскивание по правой части экрана — камера, **Бить** (удерживать) — добыча/атака,
**Исп.** — поставить блок / открыть верстак, печь, сундук / съесть, ⤒ — прыжок. Хотбар — тап по ячейке.
В инвентаре: тап — взять/положить, долгое нажатие — половина/один.

## Сборка

Нужны JDK 17 и Android SDK. Откройте проект в Android Studio или выполните `gradle :app:assembleRelease`.
APK собирается GitHub Actions (`.github/workflows/build.yml`): вкладка **Actions → Build APK → Artifacts**.
Релиз с APK создаётся при пуше тега `v*`. APK подписан debug-ключом.

## Стек

Kotlin 2.2, AGP 8.13, Compose BOM 2025.12 (Material 3 1.4), OpenGL ES 3.0.

## Пока нет

Звук, ступеньки/заборы/двери, текущая вода и лава, земледелие, редстоун, предметы-сущности на земле,
Незер/Энд, торговля, зачарования. Блоки и предметы — в `core/Registry.kt`, рецепты — `core/Recipes.kt`, мобы — `game/Entities.kt`.
